Wayfinder Privacy Policy

Effective date: October 30, 2026  ·  Package ID: com.droid.wayfinder
Summary: Wayfinder is a standalone, open-source file manager for Android desktop and large-screen devices. Wayfinder operates locally on your device and collects zero personal data, analytics, telemetry, crash reports, or advertising identifiers.

1. Data Collection & Telemetry

Wayfinder does not collect, transmit, store, sell, or share any personal data, analytics, crash telemetry, advertising identifiers, or usage logs on external servers operated by the project authors. The application embeds no advertising SDKs, analytics trackers, or third-party telemetry libraries.

2. Permissions & On-Device Processing

All file browsing, indexing, previewing, archiving, checksum calculation, and search operations run locally on your device:

  • All Files Access (MANAGE_EXTERNAL_STORAGE): Used solely on your device so you can browse, search, preview, archive, extract, copy, move, rename, and organize files and folders across shared internal storage and removable USB/SD storage volumes.
  • Nearby Devices (BLUETOOTH_CONNECT with neverForLocation): Optional runtime permission used strictly to detect whether a paired smartphone is currently connected so Wayfinder can display Cross-Device or USB file-transfer mount shortcuts in the sidebar. Bluetooth is never used to infer, derive, or track physical location.
  • Network Access (INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, CHANGE_WIFI_MULTICAST_STATE): Used exclusively when you explicitly discover local-network SMB shares (mDNS / NetBIOS discovery on your local LAN) or connect to an SMB, WebDAV/WebDAVS, or FTP/FTPS server that you configure yourself. Files and credentials are transmitted only to the servers or applications you explicitly choose.
  • Cloud & Storage Access Framework (ACTION_OPEN_DOCUMENT_TREE): When you mount a cloud storage provider (such as Google Drive) or a connected phone folder through Android's system document picker, Android grants Wayfinder scoped URI access strictly to the folder trees you select. You can unmount and revoke those folder grants at any time from Wayfinder's sidebar.

3. Credential & Session Storage

  • Saved Server Credentials: When you choose to remember a password for an SMB, WebDAV, or FTP server, your credentials are encrypted locally on your device using an AES-256-GCM key stored inside the hardware-backed AndroidKeyStore.
  • Temporary Staging Caches: When opening or previewing files from archives or remote servers, temporary local cache copies stored inside Wayfinder's private cache directory are automatically pruned after 24 hours and remain inaccessible to other apps unless you explicitly open or share a file with another app.
  • Backups & Device Transfers: Cloud backups are disabled (android:allowBackup="false"), and Android device-to-device data extraction rules explicitly exclude saved server credentials, intent-guard secrets, local session preferences (settings.xml), and temporary file caches.

4. Open Source & Contact

Wayfinder is free, independent open-source software licensed under the Apache License, Version 2.0. You can audit the complete source code, review third-party open-source attributions, or report privacy and security questions via the Wayfinder GitHub repository (Issues).
